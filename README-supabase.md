# sora 空 — портфолио + админка на Supabase

Статичный сайт (`portfolio.html`) + админка (`admin.html`), которые хранят работы
в Supabase. Сервер не нужен — деплоится как статика (Vercel / Netlify / GitHub Pages).

## Файлы
| Файл | Назначение |
|------|------------|
| `index.html` | Публичный сайт. Тянет работы из Supabase, считает их количество, открывает кейс в модалке. |
| `admin.html` | Админка: вход по email/паролю, список работ, редактор кейса, загрузка картинок. |
| `config.js` | Твои ключи Supabase (URL + anon key). |
| `supabase-schema.sql` | Таблица, Storage-бакет, RLS-политики, сид из текущих 6 работ. |

---

## Настройка (5 шагов)

### 1. Ключи → `config.js`
Supabase → **Project Settings → API**:
- **Project URL** → `SUPABASE_URL`
- **anon / public** ключ → `SUPABASE_ANON_KEY`

Впиши их в `config.js`. (anon-ключ безопасно держать на клиенте — доступ ограничен RLS.)

### 2. Схема БД
Supabase → **SQL Editor → New query** → вставь содержимое `supabase-schema.sql` → **Run**.
Создаст таблицу `works`, бакет `works` для картинок, политики доступа и зальёт текущие 6 работ.

### 3. Пользователь-админ
Supabase → **Authentication → Users → Add user** → задай свой email и пароль.
Это и есть логин в админку. (Подтверждение email можно отключить галочкой при создании.)

### 4. (Рекомендуется) Закрыть регистрацию
Supabase → **Authentication → Sign In / Providers → Email** → выключи **Allow new users to sign up**.
Тогда аккаунт сможешь иметь только ты.

### 5. Проверка
- Открой `admin.html`, войди, добавь/отредактируй работу.
- Открой `index.html` — работы и счётчик подтянутся из БД, карточка открывает кейс.

## Как это работает
- **Публичный сайт** читает только опубликованные работы (`published = true`) под anon-ключом.
- **Админка** пишет/редактирует только после входа (RLS разрешает запись лишь `authenticated`).
- **Картинки** грузятся в Storage-бакет `works` (публичное чтение), URL сохраняется в строке работы.
- **Flow-страница** (`flow_url`) — отдельный HTML-файл с разбором кейса (без визуального оформления сайта). В админке можно вставить ссылку/имя файла вручную или загрузить готовый `.html` — он уйдёт в тот же бакет `works` (папка `flows/`). На сайте у кейса появляется кнопка «Смотреть флоу», которая открывает файл поп-апом (iframe) поверх модалки кейса.
- Если `config.js` не заполнен — сайт показывает демо-работы из `DEMO_WORKS` (фолбэк), ничего не падает.

## Деплой (Vercel)
1. Залей папку в Git-репозиторий.
2. Vercel → **Add New → Project** → импортируй репозиторий → Framework preset: **Other** (статика) → Deploy.
3. `config.js` лежит в репозитории с anon-ключом — это нормально (ключ публичный).
   Главное: не коммить `service_role` ключ.
