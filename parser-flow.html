Сканер цен

Каждую минуту бот проходит по Wildberries в поиске техники Apple, которая продаётся заметно дешевле рынка — и мгновенно пишет об этом в Telegram.

Шаг за шагом

Что происходит за одну проверку

  • 01

    Расписание

    Планировщик запускает проверку каждую минуту.

    Бот работает в фоне без участия человека: как только процесс запущен, он сам решает, когда пора снова пройтись по маркетплейсу — без ручного триггера.
    APSchedulerinterval · 1 мин
  • 02

    Поиск на Wildberries

    По каждому запросу из списка — первые страницы выдачи.

    Для каждого запроса («iPhone 15», «MacBook Pro M3» и т.д.) бот забирает выдачу, отсортированную по возрастанию цены — самые дешёвые лоты оказываются на виду в первую очередь.
    search.wb.rusort=priceup
  • 03

    Сверка с рынком

    Цена лота сравнивается со справочником средних цен.

    Каждая модель Apple имеет свою «эталонную» цену. Если найденный лот дешевле рынка больше, чем на заданный порог — он помечается как выгодная находка, всё остальное отсеивается молча.
    market_prices.jsonALERT_THRESHOLD
  • 04

    Уведомление в Telegram

    Находка мгновенно улетает в чат.

    Сообщение приходит с готовой карточкой: название модели, цена лота, средняя цена по рынку, бренд и прямая ссылка на карточку товара — открыть и купить можно одним касанием.
    aiogramHTML-разметка
  • 05

    Цикл повторяется

    Через минуту — снова с шага 1.

    Проверка ничего не запоминает между запусками — она просто идёт заново по всем запросам. Это делает бота устойчивым: даже если один прогон прошёл с ошибкой сети, следующий стартует как ни в чём не бывало.

Что держит всё вместе

Гибкий порог алертов

ALERT_THRESHOLD задаёт, насколько цена должна быть ниже рынка, чтобы бот среагировал — жёстче фильтр для редких, но точных находок, мягче — для полного потока предложений.

Справочник моделей

Эталонные цены по каждой модели техники Apple хранятся отдельно от кода, в market_prices.json — обновить прайс можно без единой правки логики.
