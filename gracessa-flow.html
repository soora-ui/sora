Шаг за шагом

Как проходит визит к Грации

  • 01

    Открывает бота

    Переход по ссылке и команда /start.

    Если ссылка была реферальной, бот тихо запоминает, кто привёл нового гостя — это понадобится позже, когда придёт время начислить партнёру процент с оплаты.
    deep-link ?start=ref_...
  • 02

    Подписка на канал

    Условие входа — быть подписанным на канал Грации.

    Кнопка «Я подписался» проверяет статус через Telegram API мгновенно — без ожидания и без лишних вопросов пользователю.
    get_chat_member
  • 03

    Знакомство

    Грация представляется и спрашивает имя.

    Первое сообщение задаёт тон всему диалогу: тёплый, немного загадочный — пользователь говорит с «Грацией», а не с формой регистрации.
  • 04

    Выбор услуги

    Меню из восьми направлений — на любой запрос.

    Гороскоп, расклад таро, подбор амулета, натальная карта, план ритуала, расклад на любовь, совместимость, разбор сна — каждая карточка со своей ценой и своим сценарием ответа.
    ГороскопТаро АмулетНатальная карта РитуалЛюбовь СовместимостьСон
  • 05

    Оплата

    Промокод — одной кнопкой, статус — без переспросов.

    Платёж создаётся через ЮKassa, а его статус проверяется автоматически в фоне — параллельно доступна и ручная кнопка «Проверить оплату» для спокойствия пользователя. Скидочный промокод применяется прямо в диалоге, без выхода из чата.
    ЮKassaавтопроверка статуса
  • 06

    Персональный ответ

    Ответ приходит от лица Грации — тепло и по делу.

    Под капотом — GigaChat с отдельным сценарием на каждую услугу: для таро — детальный разбор карт, для ритуала — безопасный пошаговый план, для гороскопа — лёгкий и универсальный текст. Каждый сценарий настроен так, чтобы звучать как живая речь, а не как ответ модели.
    GigaChat5 сценариев-персон

Что держит всё вместе

Реферальная программа

У каждого партнёра — своя ссылка и процент с оплат приведённых клиентов. Статистика, список рефералов и заявки на вывод — в отдельном кабинет-боте, без доступа к основному коду.

Админ-панель

Промокоды и скидки, рассылки по всей базе пользователей, отчёты по рефералам в CSV — всё прямо в Telegram, без отдельной админки.
